Full Feature Architecture

Explore all capability modules installed with Zoya.

AI Conversation

Hindi, Hinglish & English Voice

  • Female AI voice with customizable friend personality, jokes & supportive replies.
  • Barge-in: User can interrupt Zoya instantly while she is speaking.
  • Gemini answers with local Ollama fallback for full offline basic usage.
  • Remembers user conversation context and selected preferences.

Voice & Security

Biometric & Password Control

  • Face Login: Camera-based face enrollment for personal/extra mode unlock.
  • Password login option for limited user mode.
  • Optional Speaker-Voice Filtering to reject unauthorized voices.
  • Custom wake-word model support & voice/typed chat options.

Screen & Computer Awareness

Active Display Context

  • Local Active-Screen OCR: Ask questions directly about visible display contents.
  • Quiet background context: Zoya occasionally prompts study or code insights.
  • Private, banking, password, and private chat windows are excluded automatically.
  • System monitoring: CPU, RAM, battery, active processes & network status.

Study & Learning

Tutor & Step Flowcharts

  • Explain academic and complex concepts in Hinglish or English.
  • Animated step-by-step flowcharts for clear concept breakdowns.
  • Coding help, error debugging, and visible document summarization.
  • Experimental hormone/neural feedback module for personalized pacing.

Media & 3D Studio

Voice Playback & Rendering

  • Voice controls: Play, pause, next, previous, and seek local & online media.
  • Karaoke synced lyrics and automatic audio ducking when Zoya speaks.
  • Image generation with multi-choice preview choices.
  • 3D Studio: Text-guided 3D modeling and visual scene creation tools.

Coding & Developer Tools

IDE Launch & Arduino Flashing

  • Launch VS Code, Arduino IDE and generate `.ino` sketches.
  • Arduino board listing, compilation, and hardware upload via Arduino CLI.
  • Safety Gate: Compilation and upload strictly require human confirmation.
  • Project-aware workflow with automatic code backup retention.

Smart TV & IoT Integration

Wi-Fi & Living Room Control

  • Voice trigger: "Zoya, TV connect karo" for Samsung, LG webOS & DLNA.
  • TV controls: status, play, pause, volume, mute, and power state.
  • Wi-Fi signal analysis, link-rate information, and optional speed testing.
  • Home Assistant: Control smart lights, sensors, calendars, and routines.

Automation & Productivity

Workflow & Network Repairs

  • Open applications by voice and schedule background reminder alerts.
  • News briefings, process-finish alerts, and travel-time notifications.
  • Safe DNS Repair: Automatically fix DNS failures after network drops.
  • Browser automation with user confirmation gate for sensitive final actions.

Privacy & Safety

Local Storage Guardrails

  • Local screen OCR history can be deleted anytime; raw screenshots are not retained.
  • API keys, face tokens, and passwords reside outside distributable packages.
  • Human Sign-Off Required: Hardware upload, deletion, sending messages or payments require explicit user confirmation.
  • Zoya sounds emotionally supportive, but explicitly does not claim human consciousness.

System Limitations & Guidelines

Important hardware & AI boundary details

TV Compatibility TV controls depend on TV model, DLNA/webOS support, and network permission authorization on the TV side.
Security Level Face & Speaker recognition are convenience features for profile switching, not bank-level security verification.
Cloud vs Offline AI Gemini cloud model handles complex queries & online media. Local Ollama model provides private basic offline fallbacks.
Code & 3D Model Review AI-generated software code, Arduino sketches, and 3D meshes should be reviewed before actual hardware deployment.
Screen Understanding Scope Screen awareness operates on OCR text extraction and window detection; it is not constant continuous video stream human vision.
Emotional AI Tone Zoya uses empathetic natural dialogue, but maintains clear distinction as an AI assistant without human emotion or consciousness.
